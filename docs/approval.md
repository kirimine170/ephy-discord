# 承認ボタン

外に出る操作は，許可したユーザーが Discord のボタンで承認するまで実行しない．承認者は `discord.approver_user_ids` だけである．空なら提案自体を受け付けない．

`/ephy propose` は許可チャンネルに承認待ちのメッセージを出す．ボタンは「承認」と「却下」である．

- `kind=reply`：承認されると，同じ許可チャンネルへ返信を投稿する．これが今実行される唯一の外向き操作である．
- `kind=stub`：承認は記録するが，外部への送信はしない．「この操作はまだ実行しません．」と返す．

期限は `approval.expiry_seconds`（既定 900 秒）である．期限後のボタンは期限切れになり，投稿しない．判断は監査ログへ，操作 ID と結果だけを書く．本文は書かない．

承認者は Interaction のユーザー ID だけを見る．表示名や，コネクタから届いた本文は承認にならない．返信の送信結果が不明なときは `post_unknown` として止め，自動では再送しない．
